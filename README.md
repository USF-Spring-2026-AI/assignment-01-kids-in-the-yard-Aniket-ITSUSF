## Which tool(s) did you use?
Claude Sonnet 4.6

## If you used an LLM, what was your prompt to the LLM?
```text
You are a Staff software engineer in python and have to review this code written by a junior developer.

The problem statement here is to build a family tree based on the data in the csv files.

Go through the code base and pinpoint improvements that could be made to make this even more efficient and also point out the shortcomings in this code.
```
## What differences are there between your implementation and the LLM?
- Not major syntactical differences, but the LLM did point out some edge cases that I had not considered.
- The LLM also provided a more structured and detailed review than I would have.

## What changes would you make to your implementation in general based on suggestions from the LLM?
- I would fix the critical gaps that affect the logic of the code.
- I would add try catch blocks whereever needed for efficinet error handling.
- I would add more validation to the code to ensure that the data is correct.
- I would refactor the code to make it more efficient.

## What changes would you refuse to make?
- I would not change the fundamental structure of the code.
- I would not change the way the code is organized in a huge code base as many other components depend on it.
